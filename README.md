# Dog Reviews the Mailman

A one-line review, written by the dog himself:

> He is the only friend I have who visits every day and never comes inside. I have decided he is shy, and I bark to encourage him.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the review to `out/entry.txt` (128 characters, no trailing newline).
